INSTRUCCIONES DE INSTALACIÓN Y CONFIGURACIÓN
==============================================

## PASOS PARA EJECUTAR EL SISTEMA DE PARQUEADERO

### 1. CREAR LA BASE DE DATOS EN MYSQL

a) Abrir MySQL desde línea de comandos o MySQL Workbench
b) Ejecutar el script de crear la base de datos (si no existe):

```sql
CREATE DATABASE parqueadero_jc;
USE parqueadero_jc;
```

c) Copiar TODO el contenido del archivo STORED_PROCEDURES.sql
d) Pegarlo en MySQL Workbench o línea de comandos y ejecutar

Esto creará:
- Todas las tablas necesarias (ya deben existir)
- Todos los procedimientos almacenados (sp_insertar_cliente, etc.)

### 2. CONFIGURAR CREDENCIALES DE BASE DE DATOS

Editar el archivo: demo/src/main/java/com/example/config/ConexionDB.java

Cambiar estas líneas según tu configuración MySQL:
```java
private static final String URL = "jdbc:mysql://localhost:3306/parqueadero_jc";
private static final String USER = "root";                    // Tu usuario MySQL
private static final String PASSWORD = "JohnMorales12";      // Tu contraseña MySQL
```

### 3. COMPILAR EL PROYECTO CON MAVEN

En la terminal, navegar a la carpeta 'demo':
```bash
cd demo
mvn clean compile
```

Si hay errores de dependencias, ejecutar:
```bash
mvn clean install
```

### 4. EJECUTAR LA APLICACIÓN

Opción A - Desde Maven:
```bash
mvn exec:java -Dexec.mainClass="com.example.view.Main"
```

Opción B - Desde el IDE (Eclipse, IntelliJ, VS Code):
1. Abrir el proyecto en el IDE
2. Navegar a: demo/src/main/java/com/example/view/Main.java
3. Click derecho → Run As → Java Application

### 5. USAR LA APLICACIÓN

La aplicación abrirá una ventana principal con:
- Menú lateral izquierdo con botones: CLIENTES, VEHÍCULOS, INGRESOS, TARIFAS, SALIR
- Panel central que cambia según la opción seleccionada
- NO abre múltiples ventanas, todo está en una sola

## CALLABLESTATEMENT IMPLEMENTATION

Todos los DAOs usan CallableStatement de esta forma:

```java
// EJEMPLO: Insertar cliente
String sql = "{CALL sp_insertar_cliente(?,?,?,?)}";
CallableStatement cs = conn.prepareCall(sql);
cs.setString(1, cliente.getNombre());
cs.setString(2, cliente.getDocumento());
cs.setString(3, cliente.getTelefono());
cs.setString(4, cliente.getCorreo());
cs.execute();
```

## ARQUITECTURA MVC

Flujo de datos:
```
View (JPanel) 
    ↓
Controller (recibe eventos, llama servicios)
    ↓
Service (lógica de negocio)
    ↓

    ↓

```

## TROUBLESHOOTING

### Error: "No database selected"
Solución: Ejecutar CREATE DATABASE y USE parqueadero_jc

### Error: "Cannot call CallableStatement..."
Solución: Verificar que los procedimientos estén creados en la BD
Ejecutar nuevamente el script STORED_PROCEDURES.sql

### Error: "Connection refused"
Solución: 
- Verificar que MySQL está ejecutándose
- Verificar HOST, USER, PASSWORD en ConexionDB.java

### Error: "Driver not found"
Solución: Ejecutar mvn clean install para descargar dependencias

1. El proyecto NO usa Hibernate, JPA o Spring Boot
2. Todo es JDBC puro con CallableStatement
3. Toda la lógica de BD está en procedimientos almacenados
4. La interfaz gráfica usa Swing (nativo de Java)
5. Arquitectura completamente modular y profesional
6. Documentación completa en JavaDoc
7. Una única ventana principal, no abre JFrame separados
